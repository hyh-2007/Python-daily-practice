# Day1 Python 列表循环练习

代码：[day.py](day.py)（根据本页题目补充的参考实现）

## 题目清单
1. 数组逆序
2. 找最大值及其第一次出现下标
3. 删除重复元素，保留原有顺序

## 核心知识点
1. 列表下标：列表从0开始编号，lst[i]取下标i对应的元素；len(lst)获取列表元素个数。
2. range循环
    - range(起始,终止,步长)，终止数字取不到
    - 正向遍历：步长正数；倒序遍历：步长写-1
3. 列表追加：result.append(元素)，把元素加到新列表末尾。
4. 成员判断：x in 列表 / x not in 列表，判断元素是否在列表内。
5. 变量记录值：用变量保存当前最大值、下标，遍历过程不断比较更新。
6. 限制要求：练习题禁止直接使用内置函数max()、set()、index()，手写循环。

## 通用模板
### 模板1：生成新列表（逆序、去重）
```python
#1.定义原始列表
lst = [......]
#2.创建空列表，用来存答案
result = []
#3.for循环遍历
for 遍历变量 in 遍历范围:
    #4.判断条件
    if 条件:
        result.append(元素)
#5.循环结束，输出结果
print(result)
```

### 模板2：记录最大值与下标

```python
#1.定义原始列表
lst = [......]
#2.初始化记录变量
保存值 = lst[0]
保存下标 = 0
#3.循环从下标1开始遍历
for i in range(1, len(lst)):
    if 比较条件:
        #满足条件就更新记录变量
        保存值 = lst[i]
        保存下标 = i
#4.输出
print(......)
```

以上两个模板是思路示意，省略号和条件需要替换后才能运行。可以直接运行同目录的 `day.py` 查看完整示例。

## 参考代码说明

1. **数组逆序**：从 `len(values) - 1` 遍历到 `0`，依次追加到新列表，不修改原列表。
2. **最大值和第一次出现的下标**：先记录第一个元素，只在遇到更大的值时更新；相等时保留下标，因此能找到第一次出现的位置。空列表没有最大值，代码会给出明确错误。
3. **保持顺序去重**：按原顺序遍历，只有元素还没有出现在结果中时才追加。

三道题都不使用 `max()`、`set()` 或 `index()`。

## 运行方法与示例

在仓库根目录运行：

```powershell
python day01/day.py
```

输入列表为 `[3, 1, 5, 2, 5, 3]`，输出为：

```text
原列表： [3, 1, 5, 2, 5, 3]
逆序结果： [3, 5, 2, 5, 1, 3]
最大值： 5
最大值第一次出现的下标： 2
去重结果： [3, 1, 5, 2]
```

复习时也可以尝试单个元素、全是负数、最大值重复出现、全部元素相同等情况。
